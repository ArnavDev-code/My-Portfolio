# 🌐 Personal Portfolio Website

A modern, responsive portfolio website showcasing my journey as an aspiring **Data Analyst** and **Data Scientist**. The website highlights my projects, technical skills, certifications, experience, achievements, and provides an easy way for recruiters and collaborators to connect with me.

## 🔗 Live Demo

🌍 https://arnav-nigam-portfolio.vercel.app/

- 🎨 Modern and responsive UI
- 📱 Fully mobile-friendly design
- 👨‍💻 Professional introduction
- 📂 Featured Data Analytics & Machine Learning projects
- 🛠️ Technical skills showcase
- 📜 Certifications and achievements
